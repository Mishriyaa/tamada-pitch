# Creative & Brand Strategist Pitch Deck — Founder’s Office (Tamada Media)

An interactive, 3D-camera spatial pitch deck designed for the Founder’s Office at Tamada Media. Features fluid deck navigation, native simulated 9:16 vertical video playback, an interactive mockumentary script switcher, animated character carousels, and portfolio integration.
